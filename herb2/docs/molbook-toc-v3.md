# 《인체 속 허브의 분자생물학》 (가제) 목차 v3 — 장별 세포신호 추가

풀의 분자가 몸의 세포에 말을 거는 방식 (가제) · 이광조 · 과학과영성출판사


## 서장

### 서장. 풀 한 줌이 세포에 닿기까지
- 배정 허브: 개똥쑥 (Artemisia annua) — 아르테미시닌 / 버드나무 (Salix spp.) — 살리신
- 세포신호:
  - 세포신호의 공통 문법: 리간드 → 수용체 → 전달자 → 이차전령 → 키나아제 연쇄 → 전사인자 → 반응
  - 신호가 켜지는 네 가지 입구: GPCR, 이온채널, 효소 연결 수용체, 핵수용체
- 그림 계획: 세포신호의 공통 지도(이 책 전체의 길잡이)


## 제1부. 몸으로 들어가는 길

### 1장. 맛과 향이 먼저 말을 건다
- 배정 허브: 고추 (Capsicum annuum) — 캡사이신 → TRPV1 / 박하 (Mentha × piperita) — 멘톨 → TRPM8 / 마늘 (Allium sativum) — 알리신 → TRPA1 / 용담 (Gentiana lutea) — 겐티오피크린 → 쓴맛 수용체 TAS2R
- 세포신호:
  - 쓴맛: TAS2R(GPCR) → 거스트듀신 → PLCβ2 → IP3 → Ca²⁺ → TRPM5
  - TRP 채널: 양이온(Ca²⁺) 유입 → 탈분극 → 감각 신경 활동전위, 칼모듈린·CaMKII
- 그림 계획: TAS2R와 TRP 채널의 두 감각 신호 경로

### 2장. 장벽을 넘는 분자
- 배정 허브: 강황 (Curcuma longa) — 커큐민(낮은 생체이용률) / 후추 (Piper nigrum) — 피페린(흡수 증진) / 녹차 (Camellia sinensis) — EGCG(장 흡수 한계)
- 세포신호:
  - 장 상피 밀착연접 조절: MLCK → 근육 미오신 경쇄 인산화, ZO-1·occludin
  - 유출 수송체와 대사 효소가 만드는 신호 이전의 농도 장벽
- 그림 계획: 장 상피를 건너는 경로와 밀착연접 신호

### 3장. 장내 미생물이라는 또 하나의 약제사
- 배정 허브: 인삼 (Panax ginseng) — 진세노사이드 Rb1 → compound K / 석류 (Punica granatum) — 엘라그산 → 우롤리틴 / 센나 (Senna alexandrina) — 센노사이드의 장내 활성화 / 감초 (Glycyrrhiza uralensis) — 글리시리진 → 글리시레티닉산
- 세포신호:
  - 미생물 대사산물이 켜는 수용체: 단쇄지방산 → GPR41·GPR43, 담즙산 → TGR5·FXR, 인돌 → AhR
  - 장내분비 세포 → GLP-1 분비 → 전신 신호
- 그림 계획: 미생물 대사산물에서 숙주 수용체까지

### 4장. 간과 수송체
- 배정 허브: 세인트존스워트 (Hypericum perforatum) — 하이퍼포린 → PXR, CYP3A4, P-당단백질 / 밀크시슬 (Silybum marianum) — 실리마린 → CYP·UGT 억제 논쟁
- 세포신호:
  - 이물질 감지 핵수용체: PXR·CAR → 반응 요소 → CYP3A4·MDR1 유도(1상·2상·3상 반응)
  - 신호가 켜진 뒤 약물 농도가 바뀌는 되먹임
- 그림 계획: PXR이 켜는 해독 프로그램


## 제2부. 세포 표면에서 세포 안으로

### 5장. 막 수용체와 이온채널
- 배정 허브: 카바 (Piper methysticum) — 카바락톤 → GABA-A, 이온채널 / 발레리안 (Valeriana officinalis) — 발레렌산 → GABA-A / 대마 (Cannabis sativa) — THC·CBD → CB1·CB2 / 양귀비 (Papaver somniferum) — 모르핀 → μ 오피오이드 수용체
- 세포신호:
  - GABA-A: 리간드 개폐 Cl⁻ 채널 → 과분극 → 신경 억제
  - CB1·μ 오피오이드: GPCR(Gi/o) → 아데닐산 고리화효소 억제 → cAMP 감소, GIRK 활성, β-arrestin 경로
- 그림 계획: 이온채널형과 GPCR형 수용체의 신호 비교

### 6장. 효소를 막는 풀
- 배정 허브: 버드나무 — 살리실산 → COX / 생강 (Zingiber officinale) — 진저롤 → COX·LOX / 갈란투스 (Galanthus spp.) — 갈란타민 → 아세틸콜린에스터라아제 / 개똥쑥 — 아르테미시닌의 철-헴 활성화
- 세포신호:
  - 에이코사노이드 신호: PLA₂ → 아라키돈산 → COX/LOX → 프로스타글란딘·류코트리엔 → EP 수용체(GPCR)
  - 콜린성 시냅스: 아세틸콜린 ↔ AChE 분해 ↔ 니코틴·무스카린 수용체
- 그림 계획: 아라키돈산 연쇄와 효소 억제 지점

### 7장. 에너지와 성장의 스위치
- 배정 허브: 황련 (Coptis chinensis) — 베르베린 → AMPK / 계피 (Cinnamomum cassia) — 신남알데히드·폴리페놀 → 인슐린 신호 / 녹차 — EGCG → AMPK·mTOR
- 세포신호:
  - 에너지 센서: AMP/ATP 상승 → LKB1 → AMPK → ACC 인산화, mTORC1 억제
  - 성장 신호: 인슐린 → IRS → PI3K → Akt → mTORC1, Ras → Raf → MEK → ERK
- 그림 계획: AMPK–mTOR 에너지·성장 스위치

### 8장. 염증의 신호망
- 배정 허브: 황금 (Scutellaria baicalensis) — 바이칼린 → NF-κB / 보스웰리아 (Boswellia serrata) — 보스웰릭산 → 5-LOX·NF-κB / 뇌공등 (Tripterygium wilfordii) — 트립톨라이드 → NF-κB(독성 동반) / 감초 — 글리시리진 → HMGB1·TLR4
- 세포신호:
  - TLR4 → MyD88 → IKK → IκB 분해 → NF-κB 핵 이동 → TNF·IL-6 전사
  - NLRP3 인플라마좀 → 카스파아제-1 → IL-1β / IL-6 → JAK → STAT3
- 그림 계획: TLR4–NF-κB와 인플라마좀


## 제3부. 핵과 소기관

### 9장. 핵 수용체
- 배정 허브: 홉 (Humulus lupulus) — 8-프레닐나린제닌 → 에스트로겐 수용체 / 칡 (Pueraria lobata)·대두 (Glycine max) — 이소플라본 → ERβ / 인삼 — 진세노사이드 → 스테로이드 수용체
- 세포신호:
  - 리간드 → 핵수용체 → 공동조절자 → 반응 요소(ERE·PPRE) → 전사
  - 비유전체 경로: 막 결합 ER → PI3K·MAPK 신속 신호
- 그림 계획: 핵수용체의 유전체 경로와 비유전체 경로

### 10장. 항산화는 청소부가 아니라 신호다
- 배정 허브: 브로콜리 (Brassica oleracea) — 설포라판 → Nrf2 / 로즈마리 (Rosmarinus officinalis) — 카르노식산 → Nrf2 / 강황 — 커큐민 → Nrf2
- 세포신호:
  - Keap1 시스테인 감지 → Nrf2 안정화 → 핵 이동 → ARE → HO-1·NQO1·GCL 전사
  - ROS는 해로운 부산물이자 이차전령: 호르메시스 곡선
- 그림 계획: Keap1–Nrf2–ARE 경로

### 11장. 후성유전의 스위치
- 배정 허브: 호장근 (Reynoutria japonica) — 레스베라트롤 → SIRT1(논쟁 포함) / 녹차 — EGCG → DNMT / 브로콜리 — 설포라판 → HDAC
- 세포신호:
  - 신호에서 염색질로: HAT·HDAC의 아세틸화, DNMT의 메틸화, SIRT1의 NAD⁺ 의존 탈아세틸화
  - AMPK → NAD⁺ → SIRT1, miRNA 생합성(Dicer)과 표적 mRNA 억제
- 그림 계획: 대사 신호가 염색질을 바꾸는 길

### 12장. 미토콘드리아, 자가포식, 세포자멸
- 배정 허브: 황련 — 베르베린 → 미토콘드리아 복합체 I / 개똥쑥 — 아르테미시닌 → 암세포 철 의존 사멸 / 강황 — 커큐민 → 카스파아제·p53
- 세포신호:
  - 내인성 세포자멸: Bcl-2/Bax → 시토크롬 c → Apaf-1 → 카스파아제-9 → 카스파아제-3, p53 ↔ MDM2
  - 자가포식: AMPK → ULK1, mTORC1 억제 해제 → LC3 / 철 의존 사멸: GPX4
- 그림 계획: 세포 운명을 가르는 세 경로


## 제4부. 기관에서 읽다

### 13장. 뇌와 신경
- 배정 허브: 은행 (Ginkgo biloba) — 은행잎 플라보노이드·징코라이드 / 브라미 (Bacopa monnieri) — 바코사이드 / 인삼 — 진세노사이드 / 세인트존스워트 — 우울증과 세로토닌 재흡수
- 세포신호:
  - 시냅스 신호: GABA·글루타메이트(NMDA), 세로토닌 재흡수(SERT)
  - BDNF → TrkB → ERK·PI3K → CREB / 소교세포 TLR4 → NF-κB 신경염증
- 그림 계획: 시냅스에서 신경 가소성까지

### 14장. 대사
- 배정 허브: 황련 — 베르베린 / 여주 (Momordica charantia) — 카란틴 → AMPK / 호로파 (Trigonella foenum-graecum) — 4-하이드록시이소류신 → 인슐린 분비 / 계피 — 인슐린 신호
- 세포신호:
  - 인슐린 → IRS → PI3K → Akt → GLUT4 이동, AMPK → 포도당 흡수
  - PPAR 전사 신호, 장내분비 TGR5 → GLP-1
- 그림 계획: 인슐린·AMPK·GLP-1 신호의 교차

### 15장. 심혈관
- 배정 허브: 디기탈리스 (Digitalis purpurea) — 디곡신 → Na⁺/K⁺-ATPase / 단삼 (Salvia miltiorrhiza) — 단삼 페놀산·탄시논 / 산사 (Crataegus spp.) — 플라보노이드 / 마늘 — 알리신·황화물 → 혈관 내피, 혈소판
- 세포신호:
  - 혈관 내피: eNOS → NO → sGC → cGMP → PKG → 이완
  - 심근: Na⁺/K⁺-ATPase 억제 → NCX → 세포내 Ca²⁺ 상승 / 혈소판: TXA₂·ADP(P2Y12) 신호
- 그림 계획: NO–cGMP와 Ca²⁺ 신호

### 16장. 암
- 배정 허브: 태평양주목 (Taxus brevifolia) — 파클리탁셀 → 미세소관 / 일일초 (Catharanthus roseus) — 빈크리스틴 → 튜불린 / 희수 (Camptotheca acuminata) — 캄프토테신 → 토포아이소머라아제 I / 메이애플 (Podophyllum peltatum) — 에토포사이드 → 토포아이소머라아제 II
- 세포신호:
  - 미세소관 동역학 교란 → 스핀들 체크포인트 → M기 정지 → 세포자멸
  - 토포아이소머라아제 독성 → DNA 손상 → ATM/ATR → p53
- 그림 계획: 세포주기 체크포인트와 항암 표적


## 제5부. 분자 수준의 증거를 읽는 법

### 17장. 예측과 실증
- 배정 허브: 단삼 — 네트워크 약리학·도킹 사례 / 황금 — 다표적 사례 / 강황 — 범용 활성 사례
- 세포신호:
  - 약물–표적–경로 네트워크와 경로 농축(KEGG 등): 연결은 결합을 뜻하지 않는다
  - 도킹은 결합 가능성만 말하고 신호의 방향(작용·억제)은 말하지 못한다
- 그림 계획: 예측 네트워크에서 실증 실험까지

### 18장. 시험관에서 사람까지
- 배정 허브: 강황 — 커큐민 PAINS 논쟁 / 녹차 — EGCG / 호장근 — 레스베라트롤의 농도 문제
- 세포신호:
  - 농도–반응 곡선과 수용체 점유: 시험관 농도와 혈중 농도의 간격
  - 분석 간섭 화합물(PAINS)이 가짜 신호를 만드는 방식, 다표적 효과의 잡음
- 그림 계획: 시험관 농도와 혈중 농도의 간격

### 19장. 안전성의 분자 기전
- 배정 허브: 카바 — 간독성 / 광방기 (Aristolochia fangchi) — 아리스톨로크산 DNA 부가체 / 콤프리 (Symphytum officinale) — 피롤리지딘 알칼로이드 / 마황 (Ephedra sinica) — 에페드린 / 뇌공등 — 독성
- 세포신호:
  - 반응성 대사물 → 글루타티온 고갈 → 미토콘드리아 손상·JNK 활성 → 간세포 사멸
  - DNA 부가체 → 손상 반응 → TP53 변이 / 에페드린 → 아드레날린 수용체 → cAMP
- 그림 계획: 독성 신호의 세 경로

### 20장. 남은 질문
- 배정 허브: 앞 장 허브 전체 — 표적 지도(부록 B) / 인삼 — compound K 반응자 사례
- 세포신호:
  - 신호의 개인차: 유전 다형(CYP2D6·CYP2C19), 장내 미생물 반응자
  - 오믹스와 시스템 수준 신호 모델
- 그림 계획: 개인 간 신호 차이를 만드는 변수들
