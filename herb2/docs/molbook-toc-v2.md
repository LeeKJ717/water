# 《인체 속 허브의 분자생물학》 (가제) 목차 v2 — 장별 배정 허브 추가

부제(가제): 풀의 분자가 몸의 세포에 말을 거는 방식 · 이광조 · 과학과영성출판사 · 대중서(전문적) B5
표기: 주 허브(학명) — 핵심 분자 → 표적. 허브 이름은 한국어 독음 기준. 같은 허브가 여러 장에 나오면 장마다 다른 표적을 맡는다.

## 서장. 풀 한 줌이 세포에 닿기까지
- 개똥쑥(Artemisia annua) — 아르테미시닌 / 버드나무(Salix spp.) — 살리신. 1권의 두 사례를 분자 수준으로 다시 읽는 예고편

## 제1부. 몸으로 들어가는 길
1. 맛과 향이 먼저 말을 건다
 - 고추(Capsicum annuum) — 캡사이신 → TRPV1 / 박하(Mentha × piperita) — 멘톨 → TRPM8 / 마늘(Allium sativum) — 알리신 → TRPA1 / 용담(Gentiana lutea) — 겐티오피크린 → 쓴맛 수용체 TAS2R
2. 장벽을 넘는 분자
 - 강황(Curcuma longa) — 커큐민(낮은 생체이용률) / 후추(Piper nigrum) — 피페린(흡수 증진) / 녹차(Camellia sinensis) — EGCG(장 흡수 한계)
3. 장내 미생물이라는 또 하나의 약제사
 - 인삼(Panax ginseng) — 진세노사이드 Rb1 → compound K / 석류(Punica granatum) — 엘라그산 → 우롤리틴 / 센나(Senna alexandrina) — 센노사이드의 장내 활성화 / 감초(Glycyrrhiza uralensis) — 글리시리진 → 글리시레티닉산
4. 간과 수송체
 - 세인트존스워트(Hypericum perforatum) — 하이퍼포린 → PXR, CYP3A4, P-당단백질 / 밀크시슬(Silybum marianum) — 실리마린 → CYP·UGT 억제 논쟁

## 제2부. 세포 표면에서 세포 안으로
5. 막 수용체와 이온채널
 - 카바(Piper methysticum) — 카바락톤 → GABA-A, 이온채널 / 발레리안(Valeriana officinalis) — 발레렌산 → GABA-A / 대마(Cannabis sativa) — THC·CBD → CB1·CB2 / 양귀비(Papaver somniferum) — 모르핀 → μ 오피오이드 수용체
6. 효소를 막는 풀
 - 버드나무 — 살리실산 → COX / 생강(Zingiber officinale) — 진저롤 → COX·LOX / 갈란투스(Galanthus spp.) — 갈란타민 → 아세틸콜린에스터라아제 / 개똥쑥 — 아르테미시닌의 철-헴 활성화
7. 에너지와 성장의 스위치
 - 황련(Coptis chinensis) — 베르베린 → AMPK / 계피(Cinnamomum cassia) — 신남알데히드·폴리페놀 → 인슐린 신호 / 녹차 — EGCG → AMPK·mTOR
8. 염증의 신호망
 - 황금(Scutellaria baicalensis) — 바이칼린 → NF-κB / 보스웰리아(Boswellia serrata) — 보스웰릭산 → 5-LOX·NF-κB / 뇌공등(Tripterygium wilfordii) — 트립톨라이드 → NF-κB(독성 동반) / 감초 — 글리시리진 → HMGB1·TLR4

## 제3부. 핵과 소기관
9. 핵 수용체
 - 홉(Humulus lupulus) — 8-프레닐나린제닌 → 에스트로겐 수용체 / 칡(Pueraria lobata)·대두(Glycine max) — 이소플라본 → ERβ / 인삼 — 진세노사이드 → 스테로이드 수용체(인삼과 핵수용체 책과 연결)
10. 항산화는 청소부가 아니라 신호다
 - 브로콜리(Brassica oleracea) — 설포라판 → Nrf2-Keap1 / 로즈마리(Rosmarinus officinalis) — 카르노식산 → Nrf2 / 강황 — 커큐민 → Nrf2
11. 후성유전의 스위치
 - 호장근(Reynoutria japonica) — 레스베라트롤 → SIRT1(논쟁 포함) / 녹차 — EGCG → DNMT / 브로콜리 — 설포라판 → HDAC
12. 미토콘드리아, 자가포식, 세포자멸
 - 황련 — 베르베린 → 미토콘드리아 복합체 I / 개똥쑥 — 아르테미시닌 → 암세포 철 의존 사멸 / 강황 — 커큐민 → 카스파아제·p53

## 제4부. 기관에서 읽다
13. 뇌와 신경
 - 은행(Ginkgo biloba) — 은행잎 플라보노이드·징코라이드 / 브라미(Bacopa monnieri) — 바코사이드 / 인삼 — 진세노사이드 / 세인트존스워트 — 우울증과 세로토닌 재흡수
14. 대사
 - 황련 — 베르베린 / 여주(Momordica charantia) — 카란틴 → AMPK / 호로파(Trigonella foenum-graecum) — 4-하이드록시이소류신 → 인슐린 분비 / 계피
15. 심혈관
 - 디기탈리스(Digitalis purpurea) — 디곡신 → Na+/K+-ATPase / 단삼(Salvia miltiorrhiza) — 단삼 페놀산·탄시논 / 산사(Crataegus spp.) — 플라보노이드 / 마늘 — 알리신·황화물 → 혈관 내피, 혈소판. 와파린 상호작용(단삼 사례)
16. 암
 - 태평양주목(Taxus brevifolia) — 파클리탁셀 → 미세소관 / 일일초(Catharanthus roseus) — 빈크리스틴 → 튜불린 / 희수(Camptotheca acuminata) — 캄프토테신 → 토포아이소머라아제 I / 메이애플(Podophyllum peltatum) — 포도필로톡신 → 에토포사이드(토포아이소머라아제 II)

## 제5부. 분자 수준의 증거를 읽는 법
17. 예측과 실증
 - 단삼 — 네트워크 약리학과 도킹 사례(1권 10장의 천연물 데이터베이스와 연결) / 황금 / 강황
18. 시험관에서 사람까지
 - 강황 — 커큐민 PAINS 논쟁 / 녹차 — EGCG / 호장근 — 레스베라트롤의 농도 문제
19. 안전성의 분자 기전
 - 카바 — 간독성(1권 9장) / 광방기(Aristolochia fangchi) — 아리스톨로크산 DNA 부가체(1권 12장) / 콤프리(Symphytum officinale) — 피롤리지딘 알칼로이드 / 마황(Ephedra sinica) — 에페드린 / 뇌공등
20. 남은 질문
 - 앞 장 허브 전체의 표적 지도(부록 B)로 마무리. 약물유전체, 마이크로바이옴 반응자(인삼 compound K 사례), 오믹스

## 부록
- A. 분자생물학 용어집 / B. 표적 도감표(표적 · 허브 · 성분 · 근거 수준) / C. 참고문헌 색인

## 비고
- 배정은 제안이다. 각 허브-표적 쌍은 집필 전에 corpus(12,155편)와 z840 확장 수집분에서 근거 논문이 충분한지 확인하고, 부족하면 다른 허브로 교체하거나 "근거 약함"으로 표기한다.
- 대두, 브로콜리는 허브라기보다 식품이지만 해당 분자(이소플라본, 설포라판)의 대표 공급원이라 포함했다.
- 후보 근거가 특히 얕은 장: 1장(TRP 14편), 5장(GABA 46편), 11장(SIRT1 36편), 12장(p53 64편).
