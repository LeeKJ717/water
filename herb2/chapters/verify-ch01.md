# 1장 사실 확인 목록 (원문 대조 전)
웹 요약과 코퍼스 초록으로 확인한 것 / 기억에서 쓴 것을 구분한다. 원문 대조 필요 항목:
- Capasso (1998) Lancet 352(9143):1864 서지·DOI 및 "채찍벌레 알·버섯 가설" 서술 — 기억 기반, 미확인
- Weyrich 외 (2017) Nature 544(7650):357–361 권호·쪽, 저자 목록(생략부호 앞 순서) — 기억 기반
- Hardy 외 (2012) Naturwissenschaften 99(8):617–626 권호·쪽, 저자 목록 — DOI·제목·연도는 확인, 나머지 기억 기반
- Huffman (2003) Proc Nutr Soc 62(2):371–381 권호·쪽 — DOI는 코퍼스 확인
- Pleszczyńska 외 (2017) WJMB 33(5):83 — 웹 확인(저자 6인, 트리테르페노이드 성분)
- Beck (2005) 번역본 서지 — 기억 기반. 디오스코리데스 서술(50~70년, 5권, 약 600종, 빈 사본 512/513, 후나인 847~861)은 위키 요약에서 확인, 원전·전문서로 교차 확인 필요
- Petrovska (2012): 수메르 12처방·250+식물, 에버스 700, 신농 365/기원전 2500년, 히포크라테스 300, 테오프라스토스 500+, 디오스코리데스 944/657, 이븐 바이타르 1000+ — 2차 요약(대학 서버 PDF)으로 확인, 원문 대조 필요
- 에버스 파피루스: 20 m, 110쪽, 842 vs 700, 에버스 구입 1872 vs 1873~74 — 위키 요약, 전문서(Ghalioungui 1987 등) 필요
- 엘시드론 개체 수(5 vs 2), 쓴맛 유전자(TAS2R38) — 2차 요약
- Hardy 외 (2013) 안티쿼티 87(337):873–878 — 케임브리지 초록 확인
