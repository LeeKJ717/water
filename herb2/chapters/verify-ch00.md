# 서장 사실 확인 목록 (v1)
원고 작성 시 기억·2차 서술에 의존해 1차 문헌 대조가 필요한 항목.
1. 도유유 팀 선별 규모(처방 2,000여 건·640건·약초 약 200종·추출물 380종), 191번 시료 날짜(1971-10-04): Tu (2011) 본문 대조.
2. 523 프로젝트 개시일(1967-05-23)과 도유유 합류 연도(1969).
3. 주후비급방 인용 문구와 저술 시기(4세기 중반, 갈홍).
4. 모르핀(제르튀르너, 1804경 분리·1817 발표)과 퀴닌(펠르티에·카방투, 1820): 1차 문헌 확인.
5. Ekor (2014)의 "80% 이상" 문장 원문 대조(WHO 인용 방식).
6. 위더링 1785 서지 사항(출판사 M. Swinney).
